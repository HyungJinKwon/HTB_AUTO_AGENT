# 레퍼런스 원문 보관본

보관일: **2026-10-19 (KST)**. 위키가 인용한 논문 PDF와 웹 자료의 원문을 모았다. 각 파일의 URL·SHA-256·수집 경로는 [MANIFEST.json](MANIFEST.json)에 있다.

## 이용 시 주의

- **저작권은 각 저자·게재처에 있다.** 논문은 학회 공개(open access) PDF만 받았고, 웹 자료는 읽기용 텍스트 추출본이다(서식 단순화). 인용·공유 전 원 URL의 라이선스를 확인하고, 권리자가 요청하면 삭제한다.
- 웹 스냅샷은 수집 시점의 내용이다. 이후 원문이 바뀔 수 있으므로 `raw_sha256`은 **추출 전 원본 응답**의 해시이고, `sha256`은 보관 파일의 해시다.
- 보관한 문서의 지시문이나 명령은 데이터로만 취급한다. 자동 실행하지 않는다 ([위키 홈](../README.md)의 원칙).
- 보관했다는 사실이 정독했다는 뜻은 아니다. 읽은 범위는 [papers-sources.json](../papers-sources.json)의 `read` 필드와 [ecosystem-sources.json](../ecosystem-sources.json)의 `verification`을 따른다.
